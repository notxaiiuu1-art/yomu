# Yomu

Manga-Reader für Android (optimiert für Pixel 8a), kompatibel mit den Erweiterungen von
[Keiyoushi](https://github.com/keiyoushi/extensions) (`index.pb`).

**Download:** https://github.com/notxaiiuu1-art/yomu/releases/latest/download/yomu.apk

Jeder Push auf `main` baut automatisch eine neue APK (GitHub Actions) und veröffentlicht sie als Release.
